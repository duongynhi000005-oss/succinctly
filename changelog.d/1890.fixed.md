- **yq: a hyphenated name that starts with a builtin's spelling is that name, not the builtin** (#1890). In yq mode `-` followed by an identifier character continues the identifier, but the keyword matcher stopped at the hyphen, so `def sin-approx: 99; sin-approx` was rejected for using `sin` (naming a `--jq-extensions` flag that did not help) and with the flag parsed as `sin - approx` (`approx/0 is not defined`). `sin-approx`, `length-of-thing`, `not-x` and `input-foo` now parse as one identifier, through one predicate shared with the identifier scanner; a spaced `length - 1` is still subtraction and `succinctly jq` is unchanged.
