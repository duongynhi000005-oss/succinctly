- **yq: `map(.)` over an empty container keeps the node's position, as yq does** (#3450).
  `a: []` with `.a | map(.) | path` is `["a"]` in yq and printed `[]` here, `key` printed nothing where yq says `"a"`, and `parent` printed nothing where yq says `{"a":[]}`; the same for `{}`. A non-empty container still detaches (`[]`, no `key`, no `parent`), as in yq, and a scalar still keeps its position. An alias of a non-empty container and a mapping holding only a `<<` entry are still decided differently (#4690).
  The rule asked `is_container`, which is "has a subtree" for JSON and "is a sequence or mapping" for YAML; it now asks whether the node has members, and the owned-value twin whether the array or object is non-empty. jq mode is unchanged.
