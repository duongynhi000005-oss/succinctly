- **`succinctly yq` rejects a `-` sequence line right after an explicit `?` key at the same indent** (#1104). `? k` / `- item` is no longer read as `{"k":["item"]}`: an explicit key's value must be introduced by `:`, so it now fails with a parse error where real yq fails with "did not find expected key". A bare `?` keeps parsing as before, and `k:` / `- item` is unchanged.
