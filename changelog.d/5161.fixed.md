- **jq: a `//` over a bind of an outer `$x` in a two-argument `foreach` or a `reduce` UPDATE no longer answers where jq raises** (#5161). `path(. as $x | foreach (1,2) as $i (false; try (($x as {a:$a} | 5) // 6)))` on `{"a":{"b":1}}` is `Invalid path expression with result 5` (exit 5) in jq and answered nothing with exit 0 here, so `del(...)` returned the document and `(...) |= 9` wrote through it; `del(. as $x | reduce (1,2) as $i (null; try (($x as [$a] | $a) // 5)))` on `null` was `null` where jq raises the same. `a // b` hands the truthy outputs of `a` on without a path check, so the `.` a bind in `a` ends on is checked where the fold emits it (a two-argument `foreach` its UPDATE's output, a `reduce` its final accumulator): the resolver checked the bind's own tail instead, refused `$x`'s destructure as its own guess, and the `try` (or `?`) around the `//` swallowed that refusal. The body is now read as the three-argument `foreach`'s is (#5157), the register carried into the bind and its tail left to the emission, which also names the value `//` kept (`result 5`, or `result 6` where a falsy `.` is replaced) instead of the replaced `.` or the bind's refused step. Single-pattern chains with an inert right operand (a constant, the loop's `$i`, arithmetic of them), every bind under a `//`; a bind outside one is the emission itself and is read as before. Over 51,975 sampled grid rows each (document x INIT x source x bind x tail x `//` wrapper x `path`/`del`/`|=`) against `/usr/bin/jq` 1.7.1 and a `main` build (`scripts/jq-fold-update-alt-bind-sweep.py --fold foreach2|reduce`): a two-argument `foreach` has 3,775 rows that were refused, answered wrongly or worded the error differently now match (250 were wrong accepts) and a `reduce` 4,234 (132), none that matched differ. The same `//` in a three-argument `foreach` (55,440 rows) gains the `$i` operand: 343 rows match (36 were wrong accepts), none lost. Still a wrong accept (`docs/compliance/jq/limitations.md`, #5167): a `?//` chain behind the `//`, and a right operand that is not a constant but can be the register's node (an outer `$x`, `.`, a navigation, the loop's `$i` over a source that navigates).
