- **yq: `first(f)` is the first child of the context for which `f` is truthy, as in yq, not jq's first output of `f`** (#2377).
  `[{"a":1},{"a":2}] | first(.a == 2)` answered `false` and `first(.a)` raised `Cannot index array with string "a"`; both now match yq (`{"a":2}`, `{"a":1}`). The result keeps the child's path, so `first(.a == 2) |= x`, `del(first(.a == 2))`, `path` and `key` follow it. A scalar or null context has no children and answers nothing. jq mode is unchanged. `--jq-extensions` does not restore jq's meaning (`limit(1; f)` is the jq spelling).
