- **`succinctly yq`'s `split`, `test`, `match`, `capture` and `sub` read an argument that yields no output as an empty string, as yq does** (#4903). `"a1b" | split(.foo)` is `["a","1","b"]` in yq (an absent key is the empty separator, so the string splits into characters) and `"a1b" | test(.foo)` is `true`; `succinctly yq` printed nothing for both. The same holds for `match`, `capture` and the pattern of `sub` (`"a1b" | sub(.foo; "X")` is `"XaX1XbX"`, including `sub/3`), and for the flags slot of the two-argument forms (`test("a"; .foo)`). `sub`'s replacement slot is a separate divergence (#4905). An argument that raises still raises. `succinctly jq` is unchanged: jq's `f(empty)` is `empty`.
