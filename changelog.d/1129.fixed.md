  `.a = .a` rewrote the untouched field to that spelling); yq answers the digits as written, `99999999999999999999`, while its JSON
  encoder still prints the double it parsed (`100000000000000000000.0`), which `-o=json` and `@json` keep doing. The digits ride
  with the value as its literal text and every yq JSON writer asks for the rounded spelling; `+`-signed and leading-zero spellings
  (not valid JSON number text) and runs past 320 digits keep the float path they took before.
