- **jq: a `foreach` source that calls a `def` whose body is `$x // BRANCH` with a never-truthy argument now destructures the register as jq does** (#4760, #4739).
  `path(def f($x): $x // (. as {b:$b} | .); foreach f(false) as $y (.; .; .))` on `{"a":true}` raises `Invalid path expression` in jq and printed `[]` here (`null` document: `["b"]`). The `//` always reaches `BRANCH` when its left is `false`/`null`, so the call is `BRANCH`. A truthy argument and a body that names a parameter elsewhere are unchanged.
