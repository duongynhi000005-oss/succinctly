- **yq: a plain or single-quoted scalar, a key or a one-line block scalar with a character the emitter will not write raw is double-quoted, as yq does** (#4858, #4850).
  `printf "a: 'x\x7fy'\n" | yq '.'` is `a: "x\x7Fy"` in yq and was echoed single-quoted with the raw DEL; the same for a plain scalar, a flow element (`[x<DEL>y]`), a key, a tab inside single quotes, a C1 control, U+FEFF and a character outside the BMP (`"\U0001F600"`), and for a `|-` / `>-` block scalar holding one, which stayed a block (a tab inside a block scalar does too, in yq). The line-break characters U+0085, U+2028 and U+2029 follow the line-break rules and are unchanged.
