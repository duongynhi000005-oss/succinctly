- **yq: a second comment block after a blank line, following a foot block that closed a nested mapping, is the foot of the key that owns it** (#5053, item 2). `printf 'a:\n  b: 1\n  # A\n\n  # B\nc: 2\n' | yq .` is `a:\n  b: 1\n  # A\n# B\n\nc: 2\n` (`# A` stays on `.a.b`'s key; go-yaml ended the inner block at `# A`, so `# B` is `.a`'s, printed at column 0 with the blank line that separates it from `c`); succinctly kept `# B` at column 2 on `.b`. Also before a `---` and on `-P` and writes. It applies when exactly one blank line separates the blocks, the first sits at the open block's own column and the next key dedents past it; two blank lines, a first block at an odd column or left of the open block, a next key at the same level and a block at the end of the document keep the placement they had. The owner is the last key of the mapping the following key belongs to, so three-level shapes work too. The second block may sit at any column (`    # B` after `  # A`), a blank line after it changes nothing, and a third or fourth block keeps the blank line between blocks, as yq does (`# B\n\n# C` on `.a`'s key). A second block left of the closed column at the column of a block still open (`  # B` after `    # A` in a three-level shape) keeps the placement it had.
