- **library: a duplicate-key collapse no longer merges two different complex YAML keys** (#1740). A YAML key
  with no scalar form (`? {}`, `? [1]`, a non-string alias) stringifies to `""`, so evaluating a `YamlValue`
  under `JqSemantics` (library API only: `sjq` reads JSON and `syq` evaluates under `YqSemantics`) treated
  `? {}: 1` / `? []: 2` as one repeated key and kept only the last. Such a key now has no identity hash, as a key
  that will not decode already did (#1385), so both entries survive.
