- **jq: a `reduce` source `try error(FRESH) catch (. as PATTERN | ..)` no longer answers where jq raises** (#4877).
  The handler runs on the error's payload, a value built afresh that is no node of jq's path register, so the
  pattern's step raises its own `near attempt to access element` error. The source was driven by value, so
  `path(reduce (try error({a:1}) catch (. as {b:$b} | .)) as $y (.; .))` answered `[]`, `|= 9` wrote the
  root and `del` deleted it, alone and as the source of a `reduce` in a `foreach` UPDATE. All three now raise
  as `/usr/bin/jq` 1.7.1 does.
