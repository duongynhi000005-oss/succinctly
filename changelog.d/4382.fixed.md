- **yq: `line` and `column` of a node read from JSON input are `0`** (#4382). yq decodes JSON without keeping positions, so
  `echo '{"a":1}' | yq -p json '.a | [line,column]'` and the same over a `.json` file print `[0,0]`; succinctly reported the node's
  position in the JSON text (`[1,6]`). The same text read as YAML (no `-p json`, a `.yaml` file) keeps its positions. yq picks
  the decoder from the first file's extension for a multi-file run, here it is per file (#4394, not changed).
