- **`succinctly yq` keeps a node's comments, style and `&anchor` when its top-level comma has a branch that is not a node** (#4856). `printf 'x:\n  p: 1 # note\ny: 2\n' | yq '.x, .zz'` prints `p: 1 # note` then `null`; `succinctly yq` printed `p: 1` (the comment gone, and a flow sequence came out in block style, a `&a` anchor mark was lost). The same for a literal (`.x, 1`), a computation (`.x, (.y | length)`) and `.a // .b, .c`. #1361 kept the presentation for a comma of nodes only, and the first other branch turned the nodes before it into copies. The runner now answers each branch of a top-level comma on its own and prints the answers in order, including through parentheses and nested commas; an error in any branch still prints nothing. A comma inside a bigger expression (`[.x, .y]`, `(.x, .y) | f`) is read by that expression as before.
