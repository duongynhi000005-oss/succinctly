- **jq: a `?//` chain on a value that is no node of the register is read as its bare last alternative whatever its variable names, wrapper or input kind** (#4813, #4775).
  #4775 covered a `first`/`limit`/`nth` of a chain whose earlier alternatives bound no variable the last did not, on an `Array`/`Object` input. `null | path(. as $x | {a:{b:1}} | (foreach (1,2) as $i (.; foreach ((. as {a:$b} ?// $a | $a)) as $k (.; .; $k); .)) | $x)` printed `[] ["a"]` where jq prints `[] []`, `|= 9`/`del` over a `reduce` host answered where jq refuses (`9` for the root), and a `null`/boolean head (`true | ... null | foreach (nth(0; CHAIN))`) printed four paths for two. The rewrite now also takes a bare chain (no `first`/`limit`/`nth`), earlier alternatives whose variables the body never reads, and an input of any kind that differs from the register's value (the frame holds it live). Over 30,000 differential rows against `/usr/bin/jq` 1.7.1: 95 rows that differed now match, none that matched differ, none that refused now accepts; the register and fold-source sweeps show 0 regressions.
