- **jq: a `reduce` in a `reduce` UPDATE whose source destructures the register is answered as jq answers it** (#4320, eighth part).
  `path(reduce 1 as $k (.; reduce (. as {a:$a} | .) as $k (.; .)))` is `[[]]` in jq (both folds are backtracked, so the accumulator
  stays INIT's node and the register is restored on exit) and was refused with `Invalid path expression`, as were `del` (`null`),
  `=` and `|=` through it; the same held for a `def` call returning the register as the source. The nested `reduce` is now vetted
  like a nested `foreach`: a single pattern, a no-op INIT and UPDATE, and a source the resolver checks against jq's register, so a
  register an earlier UPDATE stage moved (`. as {a:$q} | reduce (. as {b:$b} | .) as $k (.; .)`) still raises as jq does.
  A nested `reduce` with a `?//` chain stays refused. Over the 129 sweep operands that spell a `reduce` (112,275 `--stage-only` rows): 126 refusals become matches, wrong accepts 8 -> 8, wrong answers 0 -> 0, none lost; a seeded 6,000-row sample of the whole grid (`--seed 7`) flips nothing.
