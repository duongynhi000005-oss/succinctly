- **jq: a `foreach` UPDATE `if . then FE else B end` over a moving source, where `FE` is a `foreach` that emits nothing, keeps jq's answer when the state is no longer truthy** (#4948). `[path(. as $x | foreach (.a,.) as $i (.; if . then (foreach (try ($x as {a:$a} | .)) as $y (.; .; .)) else . end; .a))?]` on `{"a":null}` is `[]` in jq and exited 5 here: step 1's `FE` raises at its pattern step (`$x` is not the register) and leaves nothing, so step 2 meets a `null` state, `if .` takes `else .`, and `.a` raises jq's own index error, which the `?` catches. The binary read the whole `if` as one that may have moved the register, took the `null` for a register it had lost and raised the error as a guess nothing catches. The `else` branch moves nothing, so the register stays where the source put it and the error is jq's, catchable as in jq; a `$i` EXTRACT, which printed the refusal `Invalid path expression with result {"a":null}` for the same step, now prints `[]` (`path`), deletes and writes as jq does. The bare `path(..)`, `del` and `|=` rows are unchanged.
