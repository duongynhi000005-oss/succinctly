- **yq: `@yaml` renders block-style YAML with a trailing newline, as yq does** (#1183). `{"v": 3.0*1} | @yaml`
  printed the flow-style `{v: 3.0}`; yq answers `v: !!float 3\n`. `@yaml` had its own flow-style
  copy of the value-to-YAML renderer, which is gone: it now runs the streamer behind the CLI's YAML
  output, so containers come out as block mappings and sequences, a root computed float carries its
  `!!float` tag, and a root string keeps its quoting (`"1" | @yaml` is `"1"`, `"a: b"` is `'a: b'`).
  `succinctly jq`'s `@yaml` extension follows. A flow-sourced container still prints block, since an
  owned value carries no source style (#739, #865).
