- **jq: a malformed module path is rejected as jq rejects it** (#5322). `import "../x" as m;` and `import "a/../b" as m;` were `module not found`, where jq 1.7.1 reports `Relative paths to modules may not traverse to parent directories (../x)`; `import "b/b" as m;` (or `include "b/b";`) found `b/b.jq` where jq reports `module names must not have equal consecutive components: b/b`; and a backslash in the path is `Modules must be named by relative paths using '/', not '\' (a\b)`. The checks run in jq's order before the search, left to right over the components, for `import`, a data import and `include`. `a//b`, `a/./b`, an absolute path and `b/` still pass them and are only not found.
