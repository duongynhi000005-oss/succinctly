- **jq: `(PATH | .) |= empty` deletes the slot `PATH` names, as `PATH |= empty` does** (#5150). `(.a | .) |= empty` on `{"a":[1,2,3],"b":{"b":1}}` is `{"b":{"b":1}}` in jq (so are `(.[] | .) |= empty`, `{}` on the same document, and `(.a | .[0] | .) |= empty`, `{"a":[2,3],...}`) and left `"a": null` here: `|= empty` deletes the slots the path names (jq's `_modify` ends in `delpaths`), but a path that ends on a bare `.` after a real navigation step had navigated into the slot with no way back to the container holding it, and the terminal `.` nulled the child in place. `del(.a | .)` has handled this since #2256; `|=` now resolves the step alone when only a trailing `.` (`.`, `. | .`, `(.)?`) follows it. A filter that produces a value writes the same either way. Over 18,000 grid rows (document x path x trailing identity x update filter x operator) against `/usr/bin/jq` 1.7.1 and a `main` build: 374 rows that answered wrongly now match, none that matched differ.
