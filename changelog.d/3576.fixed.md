- **yq: a float read from JSON input prints through yq's float formatter** (#3576).
  `echo '{"big":1e20,"t":-1e-7,"m":1234567.5}' | yq -p json -o json .` printed `100000000000000000000`, `-0.0000001` and
  `1234567.5`; yq prints `1e+20`, `-1e-07` and `1.2345675e+06` (shortest digits, scientific past its magnitude threshold,
  the same rule it applies to a computed float). The streaming JSON and YAML printers, the `-P` DOM route and the YAML
  emitter now agree with yq for `-o=json`, `-o=yaml` and `-P`; whole floats inside `i64` stay integers, as before.
