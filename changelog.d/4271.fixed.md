- **yq: a block scalar whose `|`/`>` header follows an anchor or tag on a line of its own reads its text** (#4271).
  `-` / `  !!str |` / `  x` read as `""` (and `a:` / `  &x |` / `  x` as `{"a":""}`, with a stray `x: b` entry when a key
  followed), losing the scalar on every read and write, where yq reads `"x\n"`. The parser now sends such a header to the
  block-scalar reader with the owning block's indent, as #4259 did for the bare header, and the value reader skips the
  properties when it looks for the owner. Same-line forms (`key: &x |`, `- &x |`) are untouched.
