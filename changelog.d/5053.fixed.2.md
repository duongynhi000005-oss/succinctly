- **yq: a blank line inside the first document's leading comment block of a CRLF file is `# \r`, as in yq** (#5053, item 3). `printf '# c\r\n\r\na: 1\r\n' | yq .` is `# c\r\n# \r\na: 1\n` (the `\r` is comment text to go-yaml, so it reads the blank line as a comment of its own); succinctly printed `# c\r\n\r\na: 1\n`. The same for a blank line before the first comment, several in a row, one before the `---` marker and a mixed LF/CRLF block, on `.`, `-P` and a write (`.z = 1`); an LF file keeps its bare blank line. Only the first document's leading block: yq's other CRLF comment placements (a key's head becoming the previous key's foot with a blank line after it, a comment after a `---`) are not reproduced, a `%YAML` directive is still dropped on the DOM route, and a header of blank lines alone (no comment) is still dropped by `-P` and writes (the streaming `.` route prints it).
