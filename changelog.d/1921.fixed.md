- **yq: `.a[] = <rhs>` no longer evaluates the RHS when there is nothing to write into** (#1921).
  `.a[] = error("boom")` on `a: []`, `a: {}`, `a: null` and a root `null` raised `boom`; yq never runs the
  right side for zero elements and prints `{"a":[]}`, `{"a":{}}`, `{"a":[]}` and `[]`. The same holds for
  the compound assignments and a nested `.a[][] = ...`; a non-empty target still evaluates the RHS, and
  `succinctly jq` is unchanged. The comma form `(.a[], .b[]) = ...` is not covered.
