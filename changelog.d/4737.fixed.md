- **yq: a `key: value` or `? key` line at the indent of an open block sequence is now an error instead of one more sequence item** (#4737, #4530).
  `a:` / `  - x` / `  c: 1` printed `{"a":["x",{"c":1}]}` at exit 0 (a mapping item invented from the line, and `a:` / `  - x` / `  - y` / `  c: 1` / `d: 2` likewise) and yq stops with `did not find expected '-' indicator`; so did a root sequence followed by `c: 1`, and `-   a: hello` / `b: 2`, which had parsed as a second top-level item through the "obvious extension" heuristic. A sequence that is a key's same-indent value (`a:` / `- x` / `c: 1`) is closed by the next entry as before, and the continuation lines of a compact mapping inside an item are unchanged.
