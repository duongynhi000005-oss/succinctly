- **jq: `path()` and a bound `$x` accept a `del`/`delpaths`/`setpath` that leaves the input untouched** (#4295). jq's
  `delpaths` returns its input as the same `jv` when the path set is empty, so `5 | path(del(.[]?))` and
  `[1] | path(del(.b?))` are `[[]]`, `path(delpaths([]))` and `path(setpath([]; .))` are `[[]]`, and a `$x` bound to a
  scalar still names it afterwards (`.a as $x | [$x | del(empty)] | .[0] | path($x)` is `[]`); succinctly raised
  `Invalid path expression`. The test is the resolved path set, never the shape: `[1] | path(del(.[]?))` and
  `{"a":1} | path(del(.b?))` still raise, as in jq. A `del` target with a side effect keeps the refusal. jq mode only.
