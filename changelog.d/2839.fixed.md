- **yq: `-p json` reads a stream of concatenated top-level values** (#2839).
  `printf '1 2' | yq -p json -o=json -I=0 .` printed an error here and `1` / `2` in yq; `{"a":1}{"a":2}`, `[1][2]` and `1,2` likewise. The input is re-read as one document per value once the single-value parse has failed, so a well-formed object or array pays nothing. `"a": 1` and `true: 1` are two values, as in yq. `--slurp`/`--eval-all`/`--inplace` do not stream (see `docs/compliance/yq/limitations.md`).
