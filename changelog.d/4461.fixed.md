- **yq: a slice bound that does not yield exactly one number is no error for a target that is not a node** (#4461). yq raises `expected to find 1 number, got N instead` only once the slice's target produced a node, after any error the target itself raised; `del(.a[(0,1):2])` on `{"b":1}` and `.a.b[(0,1):2] | key` (or `parent`, `path`) on `{"a":1}` print the document and nothing, as yq does, where they raised the count error. A present `null` or an absent key a write creates still raises it, and a target that fails (`.a.b[(0,1):2] | key` on `{"a":[1,2,3]}`) reports its own error ahead of the count.
