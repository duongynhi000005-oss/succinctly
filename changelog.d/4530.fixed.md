- **yq: a `- item` line at the indent of an open mapping, after that mapping's latest entry already has its value, is now an error instead of a dropped line** (#4530, #1104).
  `a: 1` followed by `- x` printed `{"a":1}` at exit 0 and yq stops with `did not find expected key`; so did `k: v`, `a: 1 # c`, `? k` / `: v`, a nested mapping, sequence, block scalar or multi-line flow sequence that ended on the line before, and a `-` that dedents past a nested `b:` back into its parent (`a:` / `  b: 1` / `- x`). A same-indent `-` stays the implicit value of a `key:` still waiting for one, with an anchor, tag, comment or blank lines after the colon (`k: &x`, `k:   # c`), and a bare `?` still takes it as its own content.
