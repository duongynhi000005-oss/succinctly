- **yq: a flow mapping that owns a foot comment keeps go-yaml's trailing comma** (#5058). `printf 'k:\n  - { a: 1, b: 2 }\n  # c\n' | succinctly yq .` printed `- {a: 1, b: 2}`, where yq prints `- {a: 1, b: 2,}`: go-yaml writes a `,` before the `}` of a non-empty flow mapping whose node has a foot comment. Both tools read either spelling back as the same mapping. succinctly now writes it as well, on the read route and on writes (`.k[0].a = 2`, `.k += [3]`). An empty mapping, a flow sequence, a mapping whose comment heads the next item, and the output's root are unchanged, as in yq. In the real-file sweep (8,046 files against yq v4.53.3) differing pairs went from 142 to 115, mostly GitHub workflow matrices.
