- **jq: a `foreach` whose source navigates the register retries a `try` over a `?//` bind of INIT `.`** (#4610).
  `path(foreach .[]? as $k (.; try (. as [$a] ?// $a | $a); $k))` on `[1]` is `[0]` in jq and answered nothing here, and with `.` as EXTRACT (or no EXTRACT) jq raises
  `Invalid path expression with result [1]` where the fold answered. A navigating source puts jq's register on the element, so the root-seated INIT `.` is no node of it (only a
  `null` or boolean state is still `jv_identical` to it, by kind), and a pattern step on it is refused by `path_intact` and retried by `?//`. The step compared the state with the
  *entry* register, which the root is, so the `try` swallowed the refusal; it now compares with the step register once a source or walk has moved it off the root.
