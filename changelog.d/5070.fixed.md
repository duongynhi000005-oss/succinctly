- **yaml: nothing follows a document's scalar, flow-collection or block-scalar root before the next `---`, and a root plain scalar goes on across a line that opens like an item, as in yq** (#5070). `"a"` / `b` read as the two documents `"a"` and `"b"`, `[1]` / `- b` as `[1]` and `["b"]`, `|` / `  t` / `b` as `"t\n"` and `"b"`; yq prints the root and stops at the next line (`did not find expected <document start>`), and so does `succinctly yq` now (exit 1, with no output: yq has printed the root before the error, which this does not). The other half: `text` / `- b` was `"text"` and `["b"]` where yq reads the one string `text - b`; a root plain scalar now continues across such a line. `a # c` / `b` (a comment ends the scalar) is rejected the same way, and so are the cases that #5068 left alone for a bare plain root. Takes the YAML Test Suite cases `9HCY`, `C2SP` and `KS4U` (invalid YAML that must fail) off the known-failures list. On 80,000 random small documents: no document yq accepts is rejected, about 7,100 are newly rejected that yq rejects too, and about 1,340 outputs now equal yq's; across the 13,498 YAML files on one machine no output changed.
