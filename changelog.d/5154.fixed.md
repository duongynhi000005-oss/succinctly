- **jq: `--arg`, `--argjson`, `--slurpfile` and `--rawfile` apply in command-line order, and a name keeps its first value** (#5154). `jq -nc --arg a 1 --arg a 2 '$a'` is `"1"` in jq 1.7.1 and printed `"2"`; `--arg a 1 --argjson a 2` is `"1"` too (the later `--argjson` replaced it); `--argjson j 1 --arg a 2 '$ARGS.named'` is `{"j":1,"a":"2"}` in command-line order and was `{"a":"2","j":1}`, grouped by flag kind. The four flags were applied kind by kind, each flag's values in a `Vec` of its own, with a later value replacing an earlier one. They now apply in the order argv gave them, and a name that is already bound is skipped before its value is read or parsed, as jq does: `--arg a 1 --argjson a '{bad'` is `"1"`, not a usage error.
