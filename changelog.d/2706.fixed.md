- **yq: a write followed by a navigation keeps the comments, anchors and styles the write did not
  touch** (#2706). `.a.b = "y" | .a` on `a:` / `  b: x # c` / `  d: &z "q"` / `  e: [1, 2]` printed
  `b: y`, `d: q` and a block `e:`; it now prints `b: y # c`, `d: &z "q"` and `e: [1, 2]`, as yq
  does. The same holds after `|=`, `del()` and a metadata write (`.a.b line_comment = "cc" | .a`
  no longer loses the write itself), for a tail of any static path (`.a.e`, `.a[0].b`, `.a?`), and
  per document in a multi-document stream. A navigated scalar still drops its style and anchor
  and a navigated mapping value shows neither the standalone comments printed with its key. A
  navigation that is not the tail of the pipe (`... | .a | .f = 2`) is unchanged.
