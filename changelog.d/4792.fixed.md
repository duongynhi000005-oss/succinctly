- **jq: the later steps of a `reduce` whose UPDATE holds an empty caught foreign-`$x` destructure `foreach` run on the state the empty step left** (#4792, #4778, #4777).
  `path(.a as $x | reduce (1,2) as $i (.; select(.) | (P // false)))` raises `result null` in jq (step 1 leaves `false`, step 2's `select(.)` drops it) and answered `[]` here; `select(.a) | (P // 5)` raises `Cannot index number with string "a"` (step 2 meets `5`); and in a `reduce` over `(.a,.)` a `foreach` body that changes the state (`(.; 7; .)`) ends on `null`, not `7`, because the last step's `$x` is foreign.
  The caught foreign destructure is now answered as an empty `foreach` source instead of a refusal raised at the first step, so the `reduce` carries the state it leaves into the next step as it does for any empty UPDATE; the `select`/`if` conditions, the fallback and the stages after it are no longer predicted. In a `reduce` whose source moved the register the verdict is read per step from the element's position alone.
