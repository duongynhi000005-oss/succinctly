- **yq: an input with no bytes at all is one empty document, not an error** (#4099). `printf '' | yq '.a'` is `null`, `.a = 1` is `a: 1`, `length` is `0` and `.` prints a blank line; `succinctly yq` stopped with `YAML parse error: empty input` (exit 1) for empty stdin and for an empty file, in the pipelines where an empty config is routine. It reads as the document `yq` reads it as (`null` for a `.json` input). With several inputs an empty one reads no document and the others are read, and a run of empty files reads one empty document, as in yq (`file_index` stays the file's place on the command line). `--front-matter` on an empty input, and the few outputs an empty document prints differently from a line-break one, are recorded in the yq limitations. The other items of the #4099 sweep stay open.
