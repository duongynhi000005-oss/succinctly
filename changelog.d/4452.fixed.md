- **jq: a `foreach` source bound to a call whose `def` builds its result raises in path position as jq does** (#4452).
  `def f: {a:1}; f as {a:$a} | .` as a `foreach` source destructures a value that is never jq's register, so the pattern's
  step raises (`Invalid path expression near attempt to access element "a" of {"a":1}`); the by-value drive answered the
  root instead, so `[path(...)]` was `[[]]`, `del(...)` returned `null` and `(...) = 9` wrote. The same holds through a
  second `def`, `keys`, `[.]`, and a fresh value written next to the register (`(., {a:1}) as {a:$a}`). The source is now
  placed by the resolver. A `def` body that hands the register on next to a fresh value and a `reduce` source are unchanged.
