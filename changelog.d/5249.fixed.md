- **yq: a plain `=` from a read of a node copies the node's trailing comment and flow style** (#5249). `.c = .b` over `b: [*x] # t` printed `c:` and a block `- *x`; it now prints `c: [*x] # t` as yq does, and the same for a source with no alias in it (`b: 2 # bc` copies to `c: 2 # bc`, `b: [1, 2]` to `c: [1, 2]`), for the comments and styles under a copied container, and for a comma of targets or one under a new parent. The source's comment wins when it has one and the target's stays when it has none; a flow node wins over a block one as in yq; a scalar's quoting, an explicit tag, and a source or target a later stage rewrites still print plain, recorded in `docs/compliance/yq/limitations.md`.
