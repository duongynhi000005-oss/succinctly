- **jq: a variable bound to a stage that returns its input is the register in `path()` and updates** (#4017).
  `path(.b|tostring as $y|$y)` on `{"b":"s"}` is `["b"]` and `path(.n|tonumber as $x|$x)` is `["n"]` in jq, where
  succinctly raised `Invalid path expression with result`; the same holds for `@text`, a non-matching
  `ltrimstr`/`rtrimstr`, `delpaths([])` and `setpath([]; .)`, and for the writes through them
  (`(.b|tostring as $y|$y) = 9`, `del(.b|tostring as $y|$y)`). It also closes a silent write drop:
  `(.d|ltrimstr("s") as $v|try ($v|.b?)) = 9` on `{"d":{"b":1}}` left the document unchanged, where jq writes `{"d":{"b":9}}`.
  An input that gets a fresh result (`{"b":5}|tostring`) is still refused, as in jq, and so is the stage under a
  `//`, `?` or `try` (a refusal there stays loud). jq mode only.
