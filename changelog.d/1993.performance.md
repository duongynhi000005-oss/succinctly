- **yq: `--ascii-output` no longer instantiates every JSON streamer a second time** (#1993).
  #1983's fix for `--ascii-output` dropping duplicate keys wrapped each sink in a concrete escaper, which
  monomorphized the streamers twice and cost the default `-o json` path +0.49% on an AMD Ryzen 9 7950X (all 8
  rows slower). The escaping arm now streams through one shared `dyn` sink: the release binary is 62 KB
  (Apple M4 Pro) and 74 KB (7950X) smaller and the 7950X's default path reads -1.12% median with 2 of 8 rows
  slower; the `--ascii-output` path itself pays about +1% for the virtual calls. Output identical.
