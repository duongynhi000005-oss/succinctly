- **yq: a key deleted and written again keeps nothing of the old key** (#4113). `del(.k) | .k = 1` on `&a k: v` printed `&a k: 1` (and `!Foo k: 1` for a tagged key, and the old key's quoting and comment), where yq gives the new key none of them; a closed literal written there also no longer inherits the old value's comment. `.a |= {"k": 3}` is now the same write as `.a = {"k": 3}` (it kept the old key's `!Foo`).
