- **jq: `reduce .[] as $r ({}; .[$r.name] = $r.score)` is linear again** (#5243). Since #5223 a path target whose index key was anything but a bare variable (`.[$r.name]`, `.[.k]`, `.[$i + 1]`) counted as dynamic and ran on the path-mode interpreter, which copied the accumulator on every step: 5.75 s for 20,000 records where jq takes 0.03 s. Such a key only computes a value (jq runs it as a subexpression), so the target is static and runs on the streaming walkers again, as before #5223. A key that can retry a `?//`, calls a function, holds a path expression of its own or names `nan` still runs on the interpreter.
