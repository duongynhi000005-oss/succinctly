- **yq: `module`/`import`/`include` directives are a parse error, as in yq** (#2683). `succinctly yq 'include "mylib"; length'` parsed the directive, dropped it and answered `1` for a module that does not exist; yq v4.53.3 rejects all three at the lexer (`invalid input text`) because it has no module system. yq mode now fails at parse time, with or without `--jq-extensions`; `succinctly jq` still loads modules, and a field merely named `include`/`import` is unchanged.
