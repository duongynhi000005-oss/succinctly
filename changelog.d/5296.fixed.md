- **jq: a later `import ... as f` shadows an earlier one under the same alias** (#5296). `import "s1" as f; import "s2" as f; f::e` answered from `s1`, silently, where jq 1.7.1 answers from `s2`: the last import is the nearest definition, as the last `include` already was. It shadows per name, so a name only the earlier module defines (`f::only1`) is still reachable, and a data import under a repeated alias already took the last one.
