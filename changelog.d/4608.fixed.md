- **jq: a `?//` bind whose first alternative raises a path error retries the next one in a fold body, so `try isempty(...)` over it no longer swallows the raise** (#4608, #4595).
  With `Q = . as $q ?// $z | (if $q then true else empty end | .a?)` on `null`, `path(foreach .a? as $k ({}; .; try isempty(Q)))` raises `Invalid path expression with result true` in jq and answered nothing here, and `del(foreach .a? as $k ({}; .; try (isempty(Q) or (.a | .b)?)))` deleted the document. Alternative 1 binds the state, runs `true | .a?` (`.a?` does not suppress the path error on a value that is not the register) and jq retries onto `$z`, where the branch is empty. In a `foreach`/`reduce` UPDATE or EXTRACT whose accumulator the walk places off the register that raise was final: bare, the fold refused where jq answers; under `try`, the stale raise was caught. Over 12,000 differential rows against `/usr/bin/jq` 1.7.1 (`path`, `del`, `|=`, 9 documents, `foreach` UPDATE and EXTRACT, `reduce`): 1,562 rows that differed now match, none that matched differ, no refused row now accepts.
