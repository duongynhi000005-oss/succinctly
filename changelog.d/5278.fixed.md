- **yq: an `as` in a path position or a write target runs its source's context-free stages against the empty context an absent key leaves** (#5278). `del((.zz | error("x")) as $x | .a)` and `((.zz | error("x")) as $x | .a) = 5` printed the document and exited 0; they now exit 1 with `Error: x`, as yq does. A re-emitted literal is bound too, so `del((.zz | "a") as $k | .[$k])` deletes `.a` where it deleted nothing, and `((.zz | "a") as $k | .[$k]) = 9` writes `a` where it wrote every key. The value routes got this in #5261. A constant bound there and read as a path (`del((.zz | "s") as $x | $x)`) now refuses like `del("s" as $x | $x)`, recorded in `docs/compliance/yq/limitations.md`.
