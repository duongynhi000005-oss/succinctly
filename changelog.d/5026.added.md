- **`BalancedParens::index_heap_size()`** (#5026). Reports the heap bytes of a `BalancedParens`'s navigation indices (the L0-L2 min-excess arrays, the rank directory and any select index), leaving out the parenthesis words, which may be borrowed. It puts the index at 57.9% of the bitmap with `NoSelect` and 64.2% with `WithCsPoppy`; the docs had said ~6%, and now quote the measured figure, and `docs/architecture/bitvec.md` now describes the rank directory and sampled select the code has.
