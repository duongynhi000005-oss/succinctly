- **`succinctly yq --eval-all` keeps comments, anchors, aliases and style for a filter that reads each document on its own** (#4380). `yq ea '.'` printed `a: 1` / `b: 1` for `a: &x 1 # c1` / `b: *x` because `--eval-all` evaluated through the owned-value route; plain navigation (`.`, `.a.b`, `.[]`, `..`) and a write with a literal right side (`.b.p = 9`, `.a //= 7`, `.n += 1`, `del(.a)`) now take the per-document route, which keeps all three and runs the alias redirect, matching yq v4.53.3 byte for byte. A filter that reads the document list (`[.]`, `,`, `.a = .b`, a builtin, a variable) stays on the `--eval-all` route.
