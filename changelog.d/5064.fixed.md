- **yaml: a plain scalar continued by a more-indented `key: value` line is rejected, as yq does** (#5064, shape 1). `- a\n  z: 1\n` read as `["a z", 1]`, `k:\n  - a\n    z: 1\n` as `{"k":["a z"]}` and `a\nz: 1\n` as the two values `"a z"` and `1`, with the `: ` silently turned into something else; yq stops at the `:` with `mapping values are not allowed in this context`, and so does `succinctly yq` now (the mapping-value form `k: a\n  z: 1` already did). The check runs once per plain scalar after its last line, so a scalar that ends its line pays one comparison. A `:` with no space after it (`z:b`, `http://x`) is still text. This also takes the YAML Test Suite case `2CMS` (invalid YAML that must fail) off the known-failures list. Not changed: a root-level `: v` (shape 2, which the suite requires as valid YAML).
