- **yq: a top-level comma of navigation keeps a repeated mapping key and a node's flow style** (#5283, #2645). `., .b` on `a: 1 / a: 2 / b: [1, 2]` printed `a: 2 / b: [1, 2]` and `.a, .zz` printed the first branch in block style; they now print `a: 1 / a: 2 / b: [1, 2]` and `{b: 1, c: [1, 2]}` as yq does. When every branch is navigation, stdout streams the branches one at a time through the M2 writers instead of rebuilding each as an owned tree. An error in any branch still prints nothing for the others, and a document separator is written once. `-C`, `-0`, `-i`, `-s`, `--eval-all`, `-P` and a non-navigation branch (`.a // .b`) keep the old route and its collapse. A comma now reads a document with two colliding undecodable keys the way `.` does: `.,.` echoes both entries under `""` where it raised, recorded in `docs/compliance/yq/limitations.md`.
