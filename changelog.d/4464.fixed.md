- **yq: `del()` over a comma group with an `.[]` branch no longer raises on a scalar** (#4464). `echo 5 | succinctly yq 'del(.a, .[])'` and `del(.[], .[])` printed `Cannot iterate over number (5)` where yq prints `5`, as it already did for a single `.[]` target (#2346); a string, a bool and a scalar member or array item (`del(.a[], .b)` over `a: 5`) behaved the same. The path resolver now treats `.[]` over a non-null scalar as yielding nothing in yq mode. `null` keeps raising — it is also the placeholder for an out-of-range index (`del(.[-1], .[4][])`), where dropping the branch would be silently wrong — and `succinctly jq` is unchanged.
