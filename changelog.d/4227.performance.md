- **jq: `.a?` / `.[N]?` over a scalar inside `path(f)` no longer builds the `Cannot index` message it drops** (#4227).
  A `?`/`try` around a bare field or index lookup (no handler or `catch empty`) now settles a non-null scalar
  without stepping it, as #3728 did for `.[]?`: `[.[] | path(.a? // .)]` over 2,000 integers goes from 8,022 to
  6,022 allocator calls (the settled `path(.[]? // .)` twin) and `path(.a?)` from 4,013 to 2,013, one call per
  member. Interleaved A/B on a 1M-integer array (Apple M5 Max, not idle): `path(.a? // .)` 290.8 -> 218.4 ms,
  `path(.a?)` 149.9 -> 102.6 ms. `null` (which indexes to `null`), containers, slices, a malformed value and yq
  mode still take the step; output is unchanged.
