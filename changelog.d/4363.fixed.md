- **`succinctly yq` numbers `line` from the first content line, as yq does** (#4363). yq slurps the leading blank, comment, `%` directive and `---` lines off the input before parsing, so `# c` / `k: 1` / `m: 2` has `.m` on line 2 (it was 3) and the root on `[1,1]`, and `--- [1, 2]` has `[` at column 1 (it was 5). The same holds for every document of a stream; `yq-locate`, `at_offset` and the library `YamlCursor::line` still report the editor line.
