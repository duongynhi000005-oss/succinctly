- **yq: printing a YAML document of many block records is linear, not quadratic** (#4939). The U+2028/U+2029 prefilter #4865 added to the streaming writer (`YamlString::may_hold_unicode_line_separator`) searched for its lead byte from each plain or single-quoted scalar to the end of the *document buffer*, so every such scalar printed cost O(document). It now scans only the scalar's own bytes. `sort_by(.id)` over a root array of two-field block records, interleaved A/B against the previous `main` binary on an Apple M5 Max (min of 3-5 runs, output byte-identical): 8,000 records 114.9 ms → 14.2 ms (−87.6%), 16,000 427.7 → 23.8 ms (−94.4%), 32,000 1,665 → 43.9 ms (−97.4%), 64,000 6,557 → 83.8 ms (−98.7%); the identity filter `.` over the same 64,000 records 6,419 → 35.5 ms (−99.4%). Time per doubling went from 4x to 2x. `.[0]` (no scalar is printed past the first) is unchanged (−4.3%, within noise).
