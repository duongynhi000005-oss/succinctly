- **jq: an `import`/`include` inside a `~/.jq` file is loaded** (#5339). The file's defs were kept and its directives dropped, so `import "m" as hm; def hb: hm::a;` in `~/.jq` failed with `hm::a/0 is not defined`. The directives now load as a module's do (the current directory, then `-L`), what they bring in stays private to the file (the main program sees `hb` and neither `hm::a` nor a data import's `$dd`), and one that fails to load is a compile error reported after the program's own, as in jq.
