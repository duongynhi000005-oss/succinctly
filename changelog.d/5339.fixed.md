- **jq: a `~/.jq` file's own `import`/`include` directives are resolved, as jq does** (#5339). Only the file's `def`s were kept, so `import "m" as hm; def hb: hm::a;` in `~/.jq` made `hb` fail with `hm::a/0 is not defined`; the same held for `include "inc"; def hb: g;` and a data import `import "d" as $d; def hb: $d;`. The file's directives now search the current directory and then `-L` like any module's, bind only inside the file's own defs (the main filter still cannot see `hm::a`, `g` or `$d`), and a missing one is `module not found` at exit 3, reported after the program's own directives as jq does.
