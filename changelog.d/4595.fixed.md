- **jq: a `foreach` whose EXTRACT is a `try` over a `?//` bind of a container state no longer swallows the retry** (#4595).
  `path(foreach .a? as $k ([]; .; try (. as [$a] ?// $a | $a)))` on `null` raises `Invalid path expression with result []` in jq and answered nothing here (`del`/`=` over it wrote
  where jq raises). EXTRACT's `.` is the state UPDATE stored, a computed container when INIT is one, which jq's `path_intact` refuses at the pattern's first step whatever the register is,
  so `?//` retries onto the bare alternative. #4550 marked that for UPDATE only; EXTRACT now carries the same mark when the stored state sits at neither the register nor an equal one
  (INIT `.`, a `$r` bound to the register and a `null` state are on it and are not marked).
