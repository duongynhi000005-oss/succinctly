- **yq: `last` and `last(f)` need `--jq-extensions`, as yq's lexer rejects them** (#3560). Real yq has no
  `last` (`lexer: invalid input text "last"`, v4.53.3), yet `succinctly yq 'last'` answered without the flag
  while every other jq-only name was already gated (#1512). It now fails with the same `is not part of yq's
  syntax; pass --jq-extensions` error as `limit` or `paths`, and `first` (which yq has) is untouched. Under
  the flag `last` is jq's `.[-1]` in a path too: `(.a | last) = 9` used to be discarded at exit 0 and now
  writes, and `del(.a | last)` and `path(last)` follow. `succinctly jq` is unchanged.
