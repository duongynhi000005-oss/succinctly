- **yq: a metadata write (`line_comment`, `head_comment`, `foot_comment`, `comments`, `style`, `anchor`) whose right-hand side produces no node now takes the empty text, as yq does** (#4526, #2705).
  `.a line_comment = .zz` (an absent path) printed `a: 1 # null`, `.a line_comment = .b` over a mapping printed `a: 1 # {"c":2}`, `.a style = .zz` failed with `unknown style null` and `.a anchor = .zz` wrote `&null`; yq writes nothing for all of them, and clears an existing comment, style or anchor (`a: 1 # old` becomes `a: 1`), as it does for an empty output (`select(false)`) or `|= .zz`. A container, `[]`, a variable bound to one and an absent path (`.zz`, `.b.zz`, `.zz.y`) are the no-node shapes; `null`, a scalar, a literal `{}` and the first node of a comma (`(.zz, "y")` writes `y`) are still written.
