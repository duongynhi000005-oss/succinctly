- **yq: `-=`/`*=` on an absent slice target now follow yq** (#1390). `.b[0:1] -= 5`, `.b[0:1] -= [1]` and `.b[0:1] *= [1]` on a document without `.b` raised `Cannot index null with object` where yq leaves the document alone (`b: null`), and `.b[0:1].c += 5` (any operator, with a step after the slice) raised `Cannot index array with string "c"` for the same reason. The discarded write's throwaway is now `null` once a step follows the slice, and for `-=`/`*=`, as in yq (an empty `null`-tagged sequence): `null - X` is identity, `null * [1]` is too, and `null * 5` still raises yq's arithmetic error. A plain terminal `|=`/`+=` keeps its `[]` (`length` 0, `tojson` `[]`). A non-null scalar target (`b: 5`) is unchanged.
