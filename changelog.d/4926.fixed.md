- **`succinctly yq` keeps a document's head comment through `sort`, `sort_by`, `reverse`, `unique` and `unique_by` of its root sequence** (#4926). `printf '# top\n- 2 # two\n- 1 # one\n' | yq sort` prints `# top` above `- 1 # one` and `- 2 # two`, because yq reorders the sequence node in place; `succinctly yq` kept each item's line comment but dropped the banner. The runner now prints the document's head (the first document's verbatim header and the comments above the sequence) before the reordered items. A sequence reached through a path, the comment block above a later document and the foot comment below the sequence are not covered (recorded in `docs/compliance/yq/limitations.md`). The items still stream from their own cursors, so the cost of an array sort is unchanged.
