- **`succinctly yq` decodes every file of a run with the first file's decoder** (#4394). Real yq picks the input format once, from the first file argument's extension (`.json` is JSON; `.yaml`, `.yml`, no extension and `-` are YAML), so `yq '.a' t.json t.yaml` reads both as JSON and `t.yaml t.json` reads both as YAML; this chose per file. A `-p` is still not looked at per file. A `.json` file after a `.yaml` one is read as YAML (so `-o=auto` prints `a: 1` / `---` / `{"b": 2}` as yq does), and a YAML-only file after a `.json` one is a parse error.
