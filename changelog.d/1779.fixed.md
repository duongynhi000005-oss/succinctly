- **yq: `|=` evaluates its whole update filter, so a later error aborts with no document** (#1779).
  `.x |= (1, error("boom"), 3)`, `.a |= (., error("x"))` and `.a[] |= (1, error("x"))` printed the
  document with the first output written and no error; yq raises the error and prints nothing, because
  it reads the whole filter before taking its first output. `=` and the compound assignments already
  did this; `succinctly jq` keeps jq's `_modify` reading only the first output.
