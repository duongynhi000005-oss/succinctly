- **jq: `paths(f)` over a wide object is linear, not quadratic** (#4875). `paths(f)` read each path's node back by scanning the object's members for the key, at every path, so `[paths(type == "number")]` over a 32,000 / 64,000 / 128,000-member object took 2.3 / 10.6 / 35 s; it now looks the key up in the map (0.66 / 0.12 / 0.21 s on an M4 Pro, output identical). A survey of 25 per-position steps over wide JSON objects and 23 over wide arrays found no other shape that grew faster than its input.
