- **yq: `filename` builtin** (#2648). `succinctly yq 'filename' f1.yaml f2.yaml` raised `filename/0 is not defined`; it now names each node's origin file as it was given on the command line (`./f1.yaml` stays `./f1.yaml`), `-` for stdin and an empty string under `-n`, per file on the ordinary path and per document under `--eval-all`, as yq v4.53.3 does (`select(filename == "f2.yaml")`, `.x = filename`, `map(filename)`). `succinctly jq` still rejects it, as jq 1.7.1 does. A node yq builds fresh (a literal, `[.x] | .[0]`, a slurped element) answers the file's name here where yq answers an empty string, the same provenance gap `file_index` has (documented in the yq limitations).
