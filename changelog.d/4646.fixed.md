- **yq: `--eval-all` answers the position in the file for `line` and `column` of a node read from YAML** (#4646). `--eval-all` evaluates each document through a reindexed copy of its value, so `yq ea '.a[1].b | [line,column]' t.yaml` reported the node's position in that regenerated text (`[1,14]`) where yq answers `[3,8]`, and `[.. | [line,column]]` read `[[1,1],[1,6],[1,7],[1,9],[1,14]]` for `[[1,1],[2,3],[2,5],[3,5],[3,8]]`. The position is now asked of the source document's own index by the node's path, so a merge key, an alias, an integer key, a mapping key (`.l | key | line`), the second document of a stream and the second file of a run answer as they do on the streaming route. A value built by the filter has no source node and still answers `[0,0]`.
