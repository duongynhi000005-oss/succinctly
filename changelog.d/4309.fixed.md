- **jq: a `catch` handler that navigates but never runs keeps the path register, as in jq** (#4309). `succinctly jq 'path(. as $x | try last(.a) catch .a | $x)'` on `{"a":{"b":1},"k":2}` raised `Invalid path expression with result {...}` where jq 1.7.1 prints `[]`, and the same held for `catch .a.b`, `.[0]`, `.[]`, `.[1:]` and a pipe of steps, over a `last(f)`, `select(f)` or type-filter body, through `del`, `=` and `|=`. A handler runs on the error's payload; when the body can raise only a fresh message string (a type error from a navigation step) that payload is nobody's node, so the handler raises when it runs, in jq as here, and otherwise never runs.
