- **yq: array subtraction compares numbers by their spelling, as yq does** (#4136). `[1.50] - [1.5]` removed the element because the two are equal by value, where yq's `subtractArray` pairs scalars by tag and text (`recursiveNodeEqual`) and answers `[1.50]`; the same held for `1.0 - 1.00`, `1e3 - 1E3`, `-0.0 - 0.0`, a long float against its computed value, and inside a nested array or object. A computed number is spelled the way yq formats it (`[5.0] - [2.5 * 2]` keeps the `5.0`), an int and a float still never match, and the rule is yq-only (`jq`'s `-` still compares by value). Not part of this change: `contains` compares the same way in yq (`[1.50] | contains([1.5])` is `false`) and a computed string key that reads as a number (`{(.a | tostring): 1}`) is still written unquoted.
