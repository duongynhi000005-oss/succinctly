- **yq: `del()` of a value derived from a navigated node deletes that node** (#4476). `del(.b | tostring)` raised `Invalid path expression with result "2"`; yq builds a derived value as a replacement of its source (same parent, same key), so it deletes `.b`. The same for `length`, `not` and `@json`, after any navigation (`del(.arr[] | tostring)` empties `.arr`, `del((.b | tostring), .c)` deletes both, a literal in the same `del()` still stops the delete as before). 22 documents match yq v4.53.3. Arithmetic (`del(.b + 1)`, an error in yq when the types differ), a derived document root (`del(.. | tostring)`) and the other builtins still refuse, recorded in `docs/compliance/yq/limitations.md`. The bare-root slice rows of the issue (`del(., .[2:3])`) were matched by #4979.
