- **`succinctly yq` supports `tag =`** (#2796). `.a tag = "!!str"` on `a: 1` prints `a: "1"` (and `{"a":"1"}` under `-o json`) where it used to raise `tag = ... is not yet supported`; other tags are written the way go-yaml's encoder writes an assigned tag: `!foo`, `!!float` and `!!bool` print in front of the scalar or container (`a: !!float 1`), the scalar's own tag (`!!int` on `1`, `!!timestamp` on `2001-12-14`) prints nothing, a tag without a leading `!` is `!<tag>`, a source-tagged node keeps whatever it is given, and `tag = ""` clears it. 300 text/tag/value combinations match yq v4.53.3 byte for byte; `-o json` does not yet type a value by a `!!float`/`!!int` tag, and a tag on a key node is refused.
