- **`succinctly yq`'s `contains` looks inside a nested array on its left** (#4899). `[[1]] | contains([1])`, `{"a":[1]} | contains({"a":1})` and `[[["ab"]]] | contains(["a"])` are `true` in yq, which checks every element of an array on the left for a right-hand side that is not an array; `succinctly yq` answered `false`. An object on the left still yields no scalar (`[{"a":1}] | contains([1])` is `false`), and `succinctly jq` is unchanged.
