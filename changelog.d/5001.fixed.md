- **yq: a comment on a block scalar's header line stays there** (#5001). `down: | # sql` followed by an indented body was written back as `down: |` with `# sql` after the body's last line, where inside a block scalar it is content, so a round trip turned the string `"DROP TABLE x\n"` into `"DROP TABLE x # sql\n"`. The comment now stays after the `|`/`>` indicator (and any chomping or indentation indicator, anchor and tag) for mapping values and sequence items, on `.` and on writes, as in yq.
