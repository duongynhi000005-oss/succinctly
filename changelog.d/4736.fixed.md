- **yq: an explicit value's anchor or tag followed by a block sequence on the next line no longer drops the sequence** (#4736, #4530).
  `? k` / `: &x` / `- item` printed `{"k":null}` at exit 0 and yq prints `{"k":["item"]}`; so did `: !!seq`, `: &x !!seq` and `: &x # c`. The `:` line's properties made the parser close the value as `null` before looking at the sequence, which may sit at the `:`'s own indent as it does for an ordinary `key: &x` entry; a value that really is null (`: &x` followed by an entry, `: !!str` alone) is unchanged.
