- **`@props` ends every line with a newline, the last included** (#1076). `{"a":1} | @props` was `"a = 1"`; yq's properties encoder writes `"a = 1\n"` (a bare `"x" | @props` is `"x\n"`), so the CLI printed `a = 1` and a blank line there and a single line here, and `@props | length` was one short. A value with no lines (`{}`, `[]`) is still the empty string. `@yaml` already ended this way (#1183). Over a 12-row differential against yq v4.53.3 (objects, nested arrays, scalars, `null`, `1e10*2`, `4/2`) none now differ. The float arms the issue was filed about (`1e10*2`, `2.0*1`) were fixed earlier (#2902).
