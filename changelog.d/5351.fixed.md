- **jq: a `~/.jq` file or a module that does not parse, or that holds a main expression, is a compile error** (#5351). A `~/.jq` that failed to read or parse was dropped without a word, one that held an expression after its definitions (`def hb: 1; hb`) was accepted, and a module with a main expression was loaded; jq refuses to compile anything in each case, with `jq: error: jq: error: library should only have function definitions, not a main expression` for the last two, checked straight after parsing and counted once (`jq: 1 compile error`, exit 3, whether or not the filter uses the file). A syntax error is reported with its location as a module's is, in jq's order: the file is declared ahead of the program, so the program's own missing module stops the report before it. A syntax error's wording is still succinctly's own.
