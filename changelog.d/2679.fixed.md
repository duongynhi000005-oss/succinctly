- **yq: `.a | .b line_comment = "hi"`, `.a.b | .c style = "double"` and `.[0] | .a anchor = "x"` apply the metadata write** (#2679), where they exited 1 with a `#2679` error (and, before #4599, exited 0 with the write dropped). A metadata write behind a static navigation (`.a`, `.a.b`, `.[0]`, or a pipe of them) now runs on the navigated node as a document of its own, so the subtree keeps its comments (a comment after a sequence item's `-` included), flow collections and quoting and takes the write, as yq v4.53.3 prints it (checked against it on a hand-written battery and on 600 random document, navigation and write combinations; every difference is recorded in `docs/compliance/yq/limitations.md`). A navigation to an absent node or one that answers several nodes (`.[]`, `.a[]`), a write that reads the node's own context (`key`, `path`, `line`, a comment), and a stage that calls a `def` are still refused.
