- **yq: the streaming route writes a double-quoted scalar's control characters the way yq does** (#4850).
  `succinctly yq '.'` on `a: "\a\b\e\x7f\N\_ \0 \v\f z"` wrote `\x07\x08\x1b`, `\x00`, `\x0b\x0c` (lower-case hex) and DEL and U+0085 raw, where yq writes go-yaml's escape letters `\a \b \e \0 \v \f`, `\x7F` and `\N` (any write already did). The same escape table now covers `\L`, `\P`, `\uXXXX` for what the emitter will not write raw (a leading U+FEFF) and `\UXXXXXXXX` for a character outside the BMP, which the streaming writer used to emit raw. A scalar of printable ASCII with no `"` or `\` is still written whole, without a per-character pass.
