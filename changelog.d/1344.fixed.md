- **yq: `..` and `tostream` keep a repeated mapping key** (#1344). On `a: 1 / a: 2 / b: 3`, `..`
  printed the document as `{"a":2,"b":3}` and listed `1 2 3` as its children where yq prints the
  node intact and lists `2 3` (children read the way `.[]` reads them, last occurrence wins); it
  now answers `{"a":1,"a":2,"b":3} 2 3`, byte for byte. `..` (and `recurse`, the same walk) joins the
  M2 streaming gate so a node's text is no longer re-collapsed on output. Under `--jq-extensions`,
  `tostream` walks the document like `paths` does and emits `[["a"],1],[["a"],2]` instead of
  dropping the first occurrence. `walk` and the other object-rebuilding builtins still collapse
  (they need a multimap representation, the issue's decision (b)).
