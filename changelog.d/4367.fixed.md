- **yq: a literal `-` file argument reads stdin** (#4367). `succinctly yq '.' -` failed with `failed to read file: -` (No such file or directory), where yq reads stdin for it (its help: "use '-' as a filename to pipe from STDIN"); only the no-file form read stdin here, so a run mixing files and stdin (`cat f2.yaml | yq '.' f1.yaml - f3.yaml`) could not be written. `-` is now read as stdin at the one place a file's bytes are read, on the default, slurp/`--eval-all`, M2-streaming and `--raw-input` routes alike, once: a second `-` finds stdin drained and contributes no document, as in yq (`yq '.' - -` prints one). `file_index` and `document_index` number the sources as before. Checked against yq v4.53.3 on `.`, `file_index`, `document_index`, `-N`, `--eval-all` and files on either side of the `-`.
