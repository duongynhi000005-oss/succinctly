- **jq: `select($x|not)` on a `$x` bound to `null`/`false` passes the register on in a fold source inside another fold's body, so the destructure behind it is refused where jq raises** (#4604). `path(.a as $x | reduce .[]? as $i (.; foreach (select($x|not) | . as {a:$a} | .) as $y (.; .; .)))` on `{"a":false,"b":null}` printed `[]` (and `del` returned `null`) where jq 1.7.1 raises `Invalid path expression near attempt to access element "a"`: the stage was opaque to the marker reading (`collapse_marker_pipes` looked through `select(.)`, `select($x)` and a literal only), so the destructure of the accumulator behind it was never seen. A condition decided by the marker's own value is read now: a falsy `$x` makes `select($x|not)` a pass-through, a truthy one `select(false)` (nothing is destructured, jq answers). The refusal is the resolver's guess, so the message differs from jq's and an enclosing `?`/`try` does not catch it (#4637). The bare `$x` destructure and a `null` document in a moved body remain.
