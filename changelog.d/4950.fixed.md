- **`succinctly yq` writes a YAML key over 128 bytes as an explicit `? key` entry, as yq does** (#4950). go-yaml cannot write a key longer than 128 bytes (or holding a line break) as a simple key, so yq prints `? key` and the `:` on a line of its own; #3587 did this for keys decoded from JSON only, and a key written in YAML still came out as `key: value` on the streaming `.` route, under `-P` and on the write route. The key keeps the spelling it had in the source (`-P` clears it), an anchored or tagged value keeps its anchor on the `:` line and starts its first entry on the next, and a document with no 129-byte run without a line break and no backslash never measures a key. A long key in flow context (`{? key : 1}`) and a key with a line break under `-P` (yq writes a literal block) are recorded in `docs/compliance/yq/limitations.md`.
