- **`sort_by`, `unique_by` and `group_by` read an absent key as no output, as yq does** (#4054, #4387). yq evaluates the key filter read-only, so an element lacking the key has a shorter key list instead of one holding `null`: `[{"k":3},{"k":null},{}] | sort_by(.k)` now puts `{}` before the explicit `null` rather than tying with it, and `sort_by(.x, .y)` over `[{"x":2},{"x":1},{"y":9}]` is `[{"x":1},{"x":2},{"y":9}]` (it was `{"y":9}` first). Mappings sort the same way.
