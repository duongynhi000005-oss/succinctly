- **yaml: a block scalar at an indented document root reads its content** (#5075). `  |\n  x\n` (header and content at the same column) read as the empty string, `  >\n  a\n  b\n` too, and `  |\n x: y\n` lost its content as well; yq prints `x\n`, `a b\n` and `x: y\n`. The value decoder measured the content against the header's own column, but a document's root node has no owner above it: its content only has to be indented more than column 0, wherever the header sits (an explicit indentation indicator counts from 0, so `  |2\n  x\n` is `x\n`). Unchanged: a header that follows a `---` line or other content already took that line's indent, and still does.
