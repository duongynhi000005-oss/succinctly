- **yq: a write that gives an empty flow `{}` / `[]` its first child leaves it block-styled, as yq does** (#4849).
  `printf '{}\n' | yq '.a = 5'` is `a: 5` and `x: {}` with `.x.a = 5` is `x:` / `  a: 5` in yq, where the plain route kept the flow spelling (`{a: 5}`, `x: {a: 5}`); the same for `[]` (`.[0] = 5`, `.x += [1]`), a closed literal written over the container and `--eval-all` (#4380 routes through it). The comment beside the empty flow container goes with its spelling, as in yq. A container that was already non-empty keeps its flow style (`x: {b: 1}` with `.x.a = 5` is `x: {b: 1, a: 5}` in both), and so does an empty one the write leaves empty or fills with a copied node (`.x = .y`).
