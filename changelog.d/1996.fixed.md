- **yq: `-0`/`--nul-output` no longer implies `-r` for JSON output** (#1996). `yq -o=json -0 '.a'` on
  `a: hello` printed `hello` and on `a: "b\0c"` failed with `can't serialise value because it contains
  NUL char`; yq prints `"hello"` and `"b\u0000c"` (JSON's default unwrap-scalar setting is false, only
  YAML's is true) and so does `succinctly yq` now. `-o=json -r -0` and YAML `-0` still refuse a NUL.
  `-j`/`--join-output` still implies `-r`; its reshaping is #1731.
