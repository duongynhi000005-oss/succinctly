- **yq: a comment block between blank lines before a dedenting key stays with the previous node** (#5056). Take `b:\n  s:\n  - n: a\n    u: x\n\n  # C\n\nd: 1\n`: yq prints `# C` under `u: x`, as that key's foot. succinctly moved it down to head `d`, on every YAML route and in `head_comment`/`foot_comment`. A blank line above the block no longer keeps #2811's dedent rule from applying: the block is the previous node's foot unless it sits at the next node's own column. The same holds before a `---`, which counts as a dedent to column 0. A run of such blocks keeps one blank line between them, as yq's does. In a 16,476-row grid against yq v4.53.3, 1,247 rows now match and none that matched changes. In the real-file sweep this was the commented-out steps after a GitHub workflow job's last step.
