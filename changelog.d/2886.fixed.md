- **yq: a stray comma in a YAML flow collection is a parse error, as in yq** (#2886). `printf '{"a":{"b":{,}}}' | succinctly yq -o json .` answered `{"": null}` for `{,}` (and `[1,,2]` read as `[1, null, 2]`, `{a: 1,,b: 2}` gained an empty-string key); yq v4.53.3 rejects each with `did not find expected node content`, since `,` cannot start a flow node. Both flow sequences and mappings now fail at parse time; a trailing comma (`[1,]`, `{a: 1,}`) is still accepted, as in yq. JSON-sourced input (`.json`) already rejected these (#2279, #2777).
