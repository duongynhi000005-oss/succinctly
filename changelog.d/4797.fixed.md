- **jq: a caught foreign-`$x` destructure `foreach` behind a gate, a fallback or a multi-output head is read like a bare one in a `foreach` UPDATE or EXTRACT** (#4797, #4793).
  With `P = foreach (try ($x as {a:$a} | .)) as $y (.; .; .)` on `{"a":{"b":1}}`, `path(.a as $x | reduce (1,2) as $i (.; {a:(1,2)} | P))` raises `Invalid path expression with result null` in jq and said `result {"a":2}` here: a head object whose value is a comma emits one object per value, and the `foreach` runs once per output with each run empty. A `foreach` UPDATE or EXTRACT also read the bare `foreach` and the plain literal head only, so `select(.a) | P`, `if C then P else . end`, `P // 5` and a literal head under either named the head's value (`result 1`) where jq names the fallback or the `null` the empty step left (`result 5`, `result null`); it now reads them as a `reduce` UPDATE does.
