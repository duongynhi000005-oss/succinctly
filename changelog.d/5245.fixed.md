- **jq: `path(.[$v])` with `$v = nan` is `[null]`, not a refusal** (#5245). `nan as $v | path(.[$v])` raised `Cannot set array element at NaN index` where jq answers `[null]`, and so did `path(.[$v].x)`, `path(.a[$v])` and every `path()` built on them. A NaN index is now a path component that reads as `null`; only a write that reaches it refuses, with the same message, as in jq (`.[$v] = 5`, `|=`, `+=`, `pick`). A delete through it has nothing to delete, as for the literal `.[nan]`: `{"c":null} | nan as $v | del(.c[$v])` is `{"c":null}`, as in jq, and `del`/`|= empty` on an array parent, which never return in jq 1.7.1, leave the document unchanged instead of raising.
