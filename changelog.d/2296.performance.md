  nesting-depth pre-check built a `JsonIndex` and the materialization step then built a second one over the same
  bytes. The built cursor is now handed on, with the check still ahead of any materialization (same
  `nesting depth exceeds limit of 128` message and exit code). `-i -p json '.metadata.version = "2"'`,
  interleaved A/B on an Apple M5 Max (min / median of 21 runs, output byte-identical): 50 MB −2.8% / −3.7%;
  within noise at 1 MB (+3.8% / −0.2%) and 10 MB (−0.6% / +0.7%), where startup and the write dominate.
