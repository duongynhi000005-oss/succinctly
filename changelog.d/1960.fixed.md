- **yq: a flow mapping missing a comma is rejected instead of swallowing the next entry** (#1960).
  `{a: 1 b: 2}` read as `a: "1 b: 2"`, and `.a = 9` then wrote `{a: 9}` with exit 0, silently dropping `b: 2` from the
  file. A flow plain scalar now ends at `:` followed by a blank, a line break or end-of-input (a continuation line that
  opens with `: ` included), so the parser reports `expected ',' or '}'` as yq does. A `:` before a flow indicator or
  inside a word is still content (`{a: 1:, b: 2}`, `{a: x:y}`), matching yq v4.53.3.
  A plain flow key now ends only at `:` followed by a blank, a line break, end-of-input or a flow indicator, so `[a:\n 1]`,
  `[x:y: 1]` and `{a:1}` (a key `a:1`) read as yq reads them.
