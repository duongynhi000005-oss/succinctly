- **yaml: a block scalar whose first content line is a `#` line indented deeper than its parent takes that line's indent** (#5073). `a: |-` / `  # h` / `    deep` / `  k` / `b: 1` is `{"a":"# h\n  deep\nk","b":1}` in yq and read `{"a":"# h\n  deep\nk","k":"b"}` here: content-indent detection skipped every `#` line, so the indent came from the first line after the comment (`deep`, 4) and the scalar ended early, its remaining lines read as structure (`b: 1` was gone and `k` mapped to `b`; the same in a sequence item and at the root, where a stray second value appeared). A `#` line indented deeper than the parent is content and sets the indent; one at or below the parent's indent is still a comment. Over 5,886 random block-scalar documents (header x context x line mix x tail) against yq v4.53.3 and a `main` build: 22 that read differently now match, none that matched differ; a sweep of 20,000 YAML files on disk reads byte-identically before and after.
