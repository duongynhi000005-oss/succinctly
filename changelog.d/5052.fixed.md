- **yq: a document's trailing comment blocks keep the blank line between them** (#5052). `printf 'a: 1\n\n# A\n\n# B\n' | succinctly yq .` printed `# A` and `# B` on consecutive lines, where yq keeps one blank line between them (a run of blanks collapses to one) and answers `. | foot_comment` as `"A\n\nB"`. This applies on the `.`, `-P` and write routes, and for the document before a `---`. It was the largest cluster in a fresh real-file sweep against yq v4.53.3 (Read the Docs configs end this way). A block with no blank line before it is the last key's foot, as before.
