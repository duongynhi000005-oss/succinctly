- **yq: `.a[0] | head_comment` of a scalar item written `- # c` / `    value` answers `c`** (#4268).
  The comment after the dash is the scalar item's head comment in yq; it was read as nothing. A trailing `- x # t` is still a line comment and a mapping or sequence item still keeps its comment on the dash line. A flow collection item (`- # c` / `  [1]`) and a comment on its own line between the dash and the value remain different from yq.
