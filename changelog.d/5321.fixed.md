- **jq: `modulemeta` resolves the module and answers its `deps` and `defs`** (#5321). It answered `module not found` for every string, including a module on the `-L` path; it now searches the library directories as `import` does (the current directory is not searched, as in jq) and returns the header metadata in source order, then `deps` (one object per `import`/`include`: the directive's own metadata, `as`, `is_data`, `relpath`) and `defs` (`name/arity` of each top-level `def`). A module that fails to load prints its diagnostic to stderr and answers `null`, as jq does. Metadata now keeps its source order, accepts `null` and string keys; a metadata value that is an expression (`module {a:(1+2)};`) is still a parse error (#5344).
