- **`succinctly yq` no longer adds a final line break to a literal block scalar that ends the input without one** (#4959). `printf 'a: |\n  x\n  y' | yq -o=json .` is `{"a":"x\ny"}`: clip chomping keeps one final break only if the text has it, and `succinctly yq` answered `"x\ny\n"`, and printed the header as `|` where yq prints `|-` (identity, write and `-P` routes alike). Files saved without a trailing newline end this way, and `yq -i` rewrote them with the extra break. The folded `>` was already right.
