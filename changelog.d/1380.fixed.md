- **yq: `setpath` checks its path before its value, as yq does** (#1380). A path element that is not a `!!str` or an `!!int`
  (a slice descriptor, a float including `1.0`, a sequence, a boolean, a null) is refused with `SETPATH: expected either a
  !!str or !!int in the path, found <tag> instead` before anything is navigated or the value is evaluated, where
  `setpath(["a",1.5]; 5)` wrote element 1 and `setpath(["a",{"start":0,"end":1}]; [9])` spliced a slice. A path error now
  outranks a value error (`setpath([error("p")]; error("r"))` is `p`), a string or integer key through a scalar is a no-op
  (`a: 5 | setpath(["a","b"]; 5)` is unchanged) instead of `Cannot index number`, and the count, path-array and negative-index
  refusals take yq's sentences. jq mode is unchanged.
