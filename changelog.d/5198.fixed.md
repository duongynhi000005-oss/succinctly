- **jq: a generator in a `reduce` UPDATE yields its last output to the end of the path** (#5198). `path(reduce .a as $i (5; range(3)))` named the first output (`with result 0`) where jq names the last (`with result 2`), as did `|=` and a bind of an outer `$x` ahead of the generator. A `reduce` runs its UPDATE to exhaustion and keeps the last output, so the UPDATE is now asked for all of them (#5193 did the same for `foreach`).
