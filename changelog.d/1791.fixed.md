- **yq: `join` writes a document `{}` element as the empty string** (#1791). `- {}` / `- x` joined with `","` printed `{},x`, where yq v4.53.3 prints `,x`, and so does a `{}` reached through `$x`, `[.[0]]` or `del`. yq writes the text `{}` only for an empty mapping the expression itself spelled `{}`; `join({})` still prints `1{}2`, but the literal element (`[{}] | join(",")`) is now `""` here and `{}` in yq, because this evaluator cannot tell it from a document one.
