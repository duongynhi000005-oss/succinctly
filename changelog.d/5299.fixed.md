- **jq: a number literal with no integer part (`.5`, `.00005`) is a number in a filter** (#5299). `map(select(. > .00005))` and `.5 + 1` were compile errors (`expected identifier, found '5'`), where jq reads a `.` and a digit as one number token and prints `[1]` and `1.5`. The literal keeps jq's spelling (`.50` is `0.50`, `.5e2` is `5E+1`), and a `.` and a digit after a term (`.a.5`, `.5.5`) is still a syntax error. `succinctly yq` is unchanged: its `.5` is the key `5`.
