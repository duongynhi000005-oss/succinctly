- **yq: a parenthesised `key: value` pair inside `{...}` is accepted** (#4185). `{"x": 1, ("a": 2)}` was a parse error (`expected ')', found ':'`); yq reads `:` as an ordinary binary operator, so it is `{"x":1,"a":2}`. A parenthesised run of pairs is flattened into the object's own entries, in order, and groups nest (`{("a": 2, ("b": 3))}`); a group that holds anything but pairs, or is followed by an operator, is parsed as before. Still different: a chained pair (`("a": 2: 3)`) and a pair outside an object (`("a": 2)`), which yq answers with a nested sequence.
