- **yq: a float read from JSON prints without a per-number allocation, and the tie-break correction skips its exact check unless a tie is possible** (#4915).
  #4897 made a JSON-sourced float print through yq's float formatter, which cost +28% instructions on a 17 MB array
  of ordinary floats (`yq -p json -o json .`, 9.12 G against 7.11 G). The streaming printer now formats an
  ordinary-magnitude float into a stack buffer and only takes the allocating path for a scientific magnitude or a last digit of
  `3`, and `correct_shortest_decimal_tiebreak` rejects a non-tie with one `u64` remainder (`5^k | 2n - 1`) before its exact
  arithmetic. Same bytes out; 7.55 G instructions on that file (+6% over the plain write, -17% against main) and 6.95 G
  against 8.11 G on a mix with 20% exponent forms. Measured on an Apple M-series with `/usr/bin/time -l`.
