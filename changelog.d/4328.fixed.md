- **yq: a computed-bound slice keeps an element's explicit tag** (#4328). With `- 1` / `- !!str 2` / `- !!str true`, `0 as $i | 3 as $j | .[$i:$j]` printed `[1,2,true]` and `1 as $i | .[$i:][0]` printed the number `2`, where yq prints `[1,"2","true"]` and `"2"` — a value's type changed. Both computed-slice routes (the slice itself and the fused `E[a:b][k]` read) converted each element from a bare value, which has already lost its tag, instead of through its cursor, the only thing that carries one. Literal-bound slices, per-element reads and `[.[]]` were already right. A `!!binary` or alias element still loses its kind in any slice (recorded in `docs/compliance/yq/limitations.md`).
