- **jq: `import`/`include` search the current directory ahead of `-L`** (#5327). A module or data file beside the invocation was `module not found` unless `-L .` was passed; jq 1.7.1 prepends the current directory to the search list of every import that has no `search` metadata, for the main program and for a module's own nested imports alike, so a module in the current directory also wins over one of the same name in an `-L` directory. It is the process's current directory, not the program file's or the importing module's.
