- **jq: the `--stream` flag** (#4397). `succinctly jq --stream` exited 2 with `unexpected argument '--stream'`; it now replaces each input document with the events `tostream` emits for it, as jq does: `.` sees one event at a time, `-s` slurps the events into one array, and `input`/`inputs` read them, so `fromstream(inputs)` and `1|truncate_stream(inputs)` fold them back (`-R` ignores the flag, as in jq). Rows are pinned against jq 1.7.1. Recorded divergences: jq emits events while it parses, so a document that fails part-way has already printed the events of what it finished (succinctly prints those of the documents before it, then the error), `input_line_number` is the line the document completes on rather than the line the parser is on, `--seq --stream` ignores `--stream`, a duplicate object key is emitted once, `--stream-errors` is not accepted, and the events are materialized rather than streamed in constant memory.
