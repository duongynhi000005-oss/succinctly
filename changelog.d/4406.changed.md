- **jq/yq: a navigated literal-slice read behind a separate stage no longer validates the rest of the array** (#4406). `.a[2:] | length`, `| first`, `| last`, `| .[k]` and `.a[2:][$k]` convert only the element they name, as `.[2:][0]` and `.a[2:][0]` already did (#4323), so a malformed value elsewhere in the array no longer raises: `.a[0:] | length` on `{"a":[1,1.2.3,3]}` is `3` (jq rejects the document at parse). The parenthesised spelling `(.a[0:]) | length` and a bare `.a[0:]` still validate the whole array. Recorded in `limitations.md` ("A fused slice read does not validate the rest of the range").
