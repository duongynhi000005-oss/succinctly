- **yq: `-P` and every write keep both comments on a key that holds two** (#2806). A key whose
  deferred value comes after an anchor's own comment (`a: &anc # floated` / `  b: # own` /
  `    c: 1`) holds two comments, and the DOM route printed only the floated one: `-P '.'` and
  `.a.b.c = 2`, `del(.a.d)`, `|=` all lost `# own`. They now print `b: # floated` and `# own` on
  a line of its own at the key's indent, as yq does (#1085 had fixed the plain read). A key
  whose value is a flow collection or empty still keeps the first comment only.
