- **yq: a comment floated off an absent bare item heads a compact-mapping or nested-sequence sibling, not its first key** (#2835). `- # c` / `- b: 1` printed the comment inside the second item (`- # c` / `  b: 1`) and answered it as `.[1].b | key | head_comment`; yq prints it above the item and answers `.[1] | head_comment`, and so does this now, for a sibling in the same open sequence (`- # c` / `- - 1`, `a:` / `  - # c` / `  - b: 1`, a following comment or blank line, an anchored or tagged sibling, a sibling of a nested sequence). A float from a sequence that has since closed (`k:` / `  - - # c1` / `  - - # c2`) is still the key's foot. 18 documents match yq v4.53.3; three neighbouring shapes still differ (a second absent item in between, a float from a nested sequence that closed at the sibling, an explicit-key sibling) and are recorded in `docs/compliance/yq/limitations.md`.
