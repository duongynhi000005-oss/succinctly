- **yq: a metadata assignment under an `as` binding now applies** (#2705). `.b as $x | .a line_comment = $x` on `a: 1` / `b: hi` was refused with `only supported as a top-level pipe stage`, where yq prints `a: 1 # hi`. The write pass now evaluates the binding's source, substitutes each output into the body and resolves the writes there (chains, `|=`, a value write ahead of the comment, a parenthesised binding followed by more stages, and a source that yields several values, whose forks share the node so the last write wins in each result). A write in a binding's *source*, a destructuring pattern, or a `reduce`/`foreach` body is still refused.
