  `[{"name":"n","value":2}] | from_entries`, `[{"Key":"a","Value":1}]`, `[{"k":"a","v":1}]` and
  `[null]` produced an object from jq's alias set and defaults; yq refuses each with `expected to find
  one 'key' entry but found 0 in position N` (and the same for `'value'`), and `succinctly yq` now does
  too. `[{"key":false,"value":1}]` is `{"false":1}`. `succinctly jq` is unchanged.
