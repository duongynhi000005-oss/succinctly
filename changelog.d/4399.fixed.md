- **yq: `from_entries` and `with_entries` want exactly a `key` and a `value`** (#4399, split from #2006).
  `[{"name":"n","value":2}] | from_entries`, `[{"Key":"a","Value":1}]` and `[{"key":"a"}]` produced an
  object from jq's alias set and defaults, and `[null]` and `[{"k":"a","v":1}]` produced `{"null":null}`;
  yq refuses each with `expected to find one 'key' entry but found 0 in position N` (and the same for
  `'value'`), and `succinctly yq` now does too. `[{"key":false,"value":1}]` is `{"false":1}`. `succinctly jq` is unchanged.
