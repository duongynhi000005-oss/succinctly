- **jq, yq: the empty string repeated a huge number of times is the empty string** (#5361). `"" * 100000000000000000000`, `"" * 1e1000` and `"" * 9223372036854775807` (either operand order) never finished, because the repeat loop pushed the empty string once per repetition and neither the allocation guard nor yq's byte cap fires for a zero-byte result. They answer `""` at once, as jq does after looping its `INT_MAX`-capped count and as yq does; a non-empty string is still refused before any loop.
