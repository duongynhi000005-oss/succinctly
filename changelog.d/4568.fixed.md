- **yq: `del()` through a slice-run and a negative index below the start of the sliced sequence now raises `index [N] out of range, array size is S`, as yq does** (#4568, #4542).
  `del(.a[0:2][-3])` on `{"a":[1,2,3]}` exited 0 with the document unchanged and yq exits 1 with `index [-3] out of range, array size is 2`; a scalar, `null`, mapping or empty-slice target is the `size is 0` row (`del(.a[5:9][-1])`, `del(.a[0:2][-1])` over `{"a":5}`), and a trailing `?` or a comma sibling does not rescue the call. A positive index past the end stays a no-op, but the walk goes on over `null`, so `del(.a[0:2][5][-1])` fails with size 0. An in-range negative index, a string target and a scalar element are unchanged.
