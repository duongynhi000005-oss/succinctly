- **jq: a `try` around a nested fold in a fold source on a known register leaves the source empty as jq does** (#5030). `del(. as $x | foreach (try reduce ($x as {b:$q} | .) as $w (0; .)) as $y (.a; .; .))` on `{"a":{"b":1,"c":{"b":3}},"b":2}` leaves the document in jq: the inner destructure raises (INIT `.a` moved the register off `$x`), and the `try` catches it, so the source is empty. The marker sat under the `try`, so the source was read by value and `del` deleted `.a` (`|= 9` wrote it, and `path` answered `["a"]`); the same for `(..)?`. The source now goes to the resolver, which runs the `try` as jq does.
