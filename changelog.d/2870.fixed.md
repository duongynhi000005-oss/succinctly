- **yq: `sort_keys(f)` no longer creates a field the path names past a fan-out** (#2870, #2855).
  `sort_keys(.a[].b)` over `a: [{b: 2, q: 1}, {q: 3}]` added `b: null` to the second element and yq leaves it alone (`sort_keys(.nope)` already did). A path through `.[]` is now spelled out element by element and an element that lacks a field the path names is dropped, in sequences and mappings and past a nested field (`.a[].b.z`); an index past the end still pads and a path with a slice keeps its route (`sort_keys(.a[0:1][])` stays unchanged).
