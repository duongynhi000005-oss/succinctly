- **yq: a write or `del()` through an array's string key now addresses the element the key spells, as the read does** (#4404, #4274).
  `[10,20,30] | .["1"] = 9` raised `Cannot index array with string "1"` and yq writes `[10,9,30]`; the same for `|=`, `+=`, `del(.["1"])`, a comma group (`(.["1"], .["2"]) = 0`, `del(.["1"], .["0"])`), a computed key (`"1" as $k | .[$k] = 9`), a mid-chain step (`.a["1"].x = 9`) and a nested array, on JSON and YAML input. `parseInt64`'s spellings (`"-1"`, `"01"`, `"0x1"`, `"+1"`) work and a string that is no integer (`"x"`, `"1.0"`) keeps the error. A fractional number key (`.[1.5]`) and a string-keyed mapping's numeric `del` are not part of this change.
