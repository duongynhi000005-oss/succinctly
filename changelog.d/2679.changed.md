- **`succinctly yq` refuses a metadata write behind a navigation stage instead of dropping it** (#2679). `.a | .b line_comment = "hi"`, and the same with `style` or `anchor`, exited 0 and printed the document without the comment; yq applies it. It now exits 1 naming the shape, and so does a user-defined `def` that a stage ahead of the write reads through. A write as the first stage, `-o json` output and a write a later stage replaces are unchanged.
